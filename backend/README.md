# Backend — Mini Binance API

API Laravel do teste técnico. Documentação completa na raiz do repositório: [`../README.md`](../README.md).

## Comandos rápidos

```bash
cp .env.example .env
composer install
php artisan key:generate
php artisan migrate
php artisan db:seed
php artisan serve
```

```bash
php artisan test
./vendor/bin/pint
php artisan route:list
```

Com Docker (na raiz do monorepo):

```bash
docker compose up -d --build
```
